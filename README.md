NFT metadata helper — stub token uri tag.

## Features

- ETH path m/44'/60'/0'
- Node crypto.createHash SHA-256 stand-in
- Vault + account derive
- node:test suite

## Prerequisites

- Node.js 20+
- Git

## Getting Started

```bash
git clone <repo-url>
cd nft-metadata-js
npm install typescript --no-save
npm run build
node dist/cli.js --help
```

## Tests

```bash
node --experimental-strip-types --test tests/*.test.ts
```
